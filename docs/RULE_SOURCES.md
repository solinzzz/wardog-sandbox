# WARDOGS 规则与数值证据

核查日期：2026-09-18。目标基线：当前公开 Early Access / Season 1，最近核查的补丁为 0.11。此文档区分官方规则、社区观测和沙盘假设；没有拿到当前客户端完整经济数据。不能把沙盘称为完全复刻的官方数值模拟器。

## 证据等级

- **官方确认**：开发者 FAQ、Steam 商店、Team17、开发者 Steam 公告原文。
- **社区观测**：公开计算器、玩家实测或媒体试玩；记录版本，不能宣称是官方现行常数。
- **模型假设**：公开资料无法确定、为运行沙盘而设的可修改参数。行为概率、战斗伤害抽象、行军时间、出生位置、地图布局均属于此类。

## 尚未官方核实、必须显式标注的模型参数

- 平局是否停表、等待破局后即发分，以及积分连续控制时间细节。
- 热区直径、移动速度、路线、钻机牵引强度和持续时间；地图精确地形、出生点、塔的位置。
- 击杀奖励的连杀、复仇、爆头、重复目标和高价值目标公式；玩家死亡/复活对现金结算的影响。
- 普通复活、治疗每 HP、侦察、修理、拆除、每名乘客、乘客后续击杀、物资卸载、建设各事件的当前现金公式。
- 当前所有装备/载具完整购买价、折扣资格、席位、解锁状态。沙盘若省略成长门槛，应注明使用预解锁研究账户。
- FOB 是否允许出生：不能把 FOB 本身直接当复活点。移动 APC 与 FOB 是不同系统；20 分解锁/生成、每人冷却等仅有版本不一的社区说法。
- NPC 决策频率、技能、好战/逐利/协同倾向、命中率、伤害、反应距离、复活等待等，全部是行为模型假设，并非游戏 AI（真实游戏由真人驱动）。

## 对推演结果的解释

本沙盘适合比较“提高协作/后勤比例”“追热区还是保命赚钱”等机制影响。单次胜负、玩家净收益与获利职业排行是指定参数和随机种子下的模型输出；它们不构成真实服务器胜率预测。参数应保持可编辑，观测数据更新时只替换对应值和版本，不把未知量隐藏成官方常数。
